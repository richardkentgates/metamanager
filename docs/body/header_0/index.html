OS-Level Daemons for
Lossless Media Processing

Daemons watch a filesystem job queue and process media files using ExifTool, jpegtran, optipng, cwebp, avifenc, and ffmpeg. WordPress writes a JSON job file. The daemon picks it up via inotifywait and processes it outside the request lifecycle.

OS-Level Daemons for
Lossless Media Processing.

Metamanager Server provides compression and metadata embedding daemons that watch a filesystem job queue and process media files using ExifTool, jpegtran, optipng, cwebp, and ffmpeg — all outside of PHP so WordPress never blocks on the hot path.

Lossless compression — images, video & audio File metadata — EXIF/IPTC/XMP, ID3, QuickTime, Vorbis Event-driven — inotifywait, no polling Security hardened — systemd sandboxing APT repository — stable + test channels

wget -qO- https://apt.richardkentgates.com/key.gpg | sudo gpg --batch --yes --dearmor -o /usr/share/keyrings/metamanager.gpg && echo "deb [signed-by=/usr/share/keyrings/metamanager.gpg] https://apt.richardkentgates.com stable main" | sudo tee /etc/apt/sources.list.d/metamanager.list && sudo apt update && sudo apt install metamanager

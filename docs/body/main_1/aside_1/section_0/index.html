Quick Install

wget -qO- https://apt.richardkentgates.com/key.gpg \
  | sudo gpg --batch --yes --dearmor \
  -o /usr/share/keyrings/metamanager.gpg

echo "deb [signed-by=/usr/share/keyrings/metamanager.gpg] \
  https://apt.richardkentgates.com stable main" \
  | sudo tee /etc/apt/sources.list.d/metamanager.list

sudo apt update && sudo apt install metamanager

Requires WordPress with the MetaManager plugin installed.
